# Contributing

Contributions are welcome through pull requests. The branch `main` receives a change only through a
pull request whose checks have passed.

## Licence

Contributions are accepted under the licence of this repository, the GNU Affero General Public License,
version 3 (see [LICENSE](LICENSE)).

## Code

- The page is one file, `site/index.html`, with its style and its script inside it, and it needs no build
  step. Keep it that way: the page must not need any other file.
- The script is plain JavaScript that runs in current browsers without a library.
- A change to a classification keeps its source, licence and citation as the page shows them.
- Run the checks listed in [README.md](README.md) before opening a pull request.

## Commits

Write the subject of a commit in the imperative, in at most 72 characters, and describe one change in each
commit.

## Changes

Record every notable change in [CHANGELOG.md](CHANGELOG.md).
